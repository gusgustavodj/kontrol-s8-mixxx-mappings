# Platform support

Project scope spans platforms; package availability is assessed separately.

| Platform | Current status |
| --- | --- |
| Windows | Existing initial implementation in `windows/`; final composition and publication remain subject to gates. See [installation](installation-windows.md). |
| Android | Private development; future inclusion planned after its own validation and authorization. No package here. |
| Linux | Requests and contributions possible; support not established. |
| macOS | Requests and contributions possible; support not established. |
| Other | Evaluated on request with platform-specific evidence. |

Compatibility on one platform does not establish compatibility on another. No release date is committed.
