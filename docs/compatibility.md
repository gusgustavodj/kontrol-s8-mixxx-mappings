# Compatibility

The Windows candidate is documented against Mixxx source revision `3ebac449e7e5fe2a0186596657696e87ce8b0e56`, the included S8 patch, and available HID and Bulk interfaces. The four-file Windows v1.0 composition retains the 7000 ms splash. The owner subsequently confirmed that this updated composition works on physical hardware. The specific Windows version, Mixxx build, patch identity and function-by-function test scope remain unrecorded; this report does not establish universal compatibility.

Android is in private development and is not included. Linux, macOS and other systems have no distributed implementation in this candidate.
